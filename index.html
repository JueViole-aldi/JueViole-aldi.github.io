Windows Server 2019 & Endpoint Windows 10 Lab

Dokumentasi & Screenshot

Praktik laboratorium mandiri dalam membangun, mengelola, dan melakukan troubleshooting jaringan Server–Client (Internal Network) menggunakan Windows Server 2019 dan Windows 10 Pro (Domain-Joined) di Oracle VM VirtualBox:

01. Active Directory (`dsa.msc`), OU & DHCP (`dhcpmgmt.msc`)

Pengelolaan akun pengguna dan Organizational Unit (OU) per divisi, konfigurasi DHCP Scope (`.10`–`.100`), penanganan Rogue DHCP / IP Conflict (ipconfig /release & /renew), serta uji konektivitas ICMP Ping dua arah (0% packet loss).

02. SMB File Server & Deployment MS Office LTSC 2021 (`.bat`)

Penyediaan Shared Folder terpusat, pemetaan Network Drive (net use Z:), serta otomatisasi instalasi Microsoft Office LTSC 2021 menggunakan Office Deployment Tool (setup.exe & Configuration.xml) melalui Batch Script.

03. Group Policy (`gpmc.msc`), Event Viewer & Firewall (`wf.msc`)

Penerapan pembatasan akses Control Panel di sisi Client via GPO (gpupdate /force & gpresult /r), pelacakan error log sistem di Windows Event Viewer, dan pengaturan aturan port pada Windows Firewall.

Linux (Ubuntu 26.04.1 LTS) Administration Lab

Dokumentasi & Screenshot

Praktik laboratorium mandiri dalam pengoperasian, pemantauan sumber daya, dan pengamanan sistem operasi Linux Ubuntu 26.04.1 LTS berbasis baris perintah (Command Line Interface / CLI):

01. Manajemen User, Grup Divisi & Hak Akses (`chmod 750`)

Pembuatan akun staf (adduser), pengelompokan grup divisi (groupadd, usermod, gpasswd), perubahan kepemilikan direktori (chown), serta pembatasan izin akses folder kerja bersama (chmod 750).

02. Manajemen Paket, Storage Audit & System Logs

Pengelolaan paket aplikasi (apt & dpkg -s), pemeriksaan kapasitas partisi dan direktori (df -h, lsblk, du -sh), pemantauan CPU/RAM & PID (htop), serta investigasi log pada /var/log/syslog dengan tail dan grep.

03. Firewall (UFW), Remote SSH Lintas OS & Backup (`tar` / Cron)

Pengamanan port layanan dengan Uncomplicated Firewall (ufw allow ssh & 80/tcp), pengujian kendali jarak jauh via OpenSSH dari CMD Windows 10, serta kompresi backup direktori (tar -czvf) dan jadwal otomatis (crontab -e).
