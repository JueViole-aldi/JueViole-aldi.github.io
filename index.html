Linux (Ubuntu Server) Administration Lab

Dokumentasi & Screenshot

Dokumentasi pengoperasian, pemeliharaan, dan pengamanan sistem operasi Linux berbasis baris perintah (Command Line Interface / CLI) untuk kebutuhan server:

01. Manajemen User, Group & Hak Akses (Permissions)

Pengelolaan akun pengguna (adduser, sudo) dan pengamanan izin akses direktori kerja menggunakan chmod serta chown.

02. Manajemen Paket, Storage & Investigasi System Log

Administrasi repositori paket (apt), pemantauan kapasitas penyimpanan (df -h, lsblk), serta pelacakan error pada /var/log/syslog.

03. Remote SSH Hardening, Backup Data & Firewall (UFW)

Konfigurasi akses jarak jauh via OpenSSH, prosedur pencadangan data (tar/rsync), serta pembatasan port dengan ufw.
